# Sistema de Controle de Tarefas e Produtividade

## Sobre o projeto

O Sistema de Controle de Tarefas é uma aplicação web desenvolvida para auxiliar na organização e no acompanhamento de atividades diárias.

A ferramenta permite cadastrar tarefas, definir prioridades, estabelecer prazos, acompanhar o andamento das atividades e visualizar indicadores de produtividade.

## Objetivo

Desenvolver uma aplicação web para demonstrar conhecimentos em desenvolvimento front-end, lógica de programação e gerenciamento de dados, simulando uma ferramenta utilizada na organização de atividades profissionais e administrativas.

## Funcionalidades

- Cadastro de tarefas.
- Edição de tarefas existentes.
- Exclusão de tarefas.
- Definição de prioridades: baixa, média e alta.
- Definição de prazos.
- Controle de status: pendente, em andamento e concluída.
- Pesquisa por título e descrição.
- Filtros por status e prioridade.
- Indicadores automáticos de produtividade.
- Armazenamento de dados com LocalStorage.

## Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e responsividade.
- JavaScript — lógica e funcionalidades.
- LocalStorage — armazenamento dos dados no navegador.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
4. Cadastre suas tarefas e utilize os filtros disponíveis.
